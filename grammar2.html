7Indefinite Pronouns Qeyri-müəyyən əvəzliklər

Some

  1. Some – bir neçə, bir qədər deməkdir. Həm sayıla bilən cəm, həm də sayılmayan tək ismin qarşısında işlənir.
    Nümunə

    Some girls — Some money

    Some tamamlıq kimi yalnız təsdiq cümlədə işlənir:

    Nümunə

    I have some girls.

    I have some money.

    Bu cümlələri sual və inkara çevirsək, some-ın əvəzinə həmişə any işlənəcək:

    Nümunə

    Do you have any money?

    I don’t have any friends.

  2. Some cümlənin mübtədası olarsa, tərcüməsi bəzi, bəziləri olur və inkar cümlədə də işlənə bilər.
    Nümunə

    Some boys like football, some don’t like. (Bəzi oğlanlar futbolu sevir, bəziləri yox.)

  3. Some bəzən təklif xarakterli cümlələrdə işlənə bilər.
    Nümunə

    Would you like some tea? (Çay içirsənmi?)

  4. Some əmr və xahiş cümlələrində də işlənə bilər.
    Nümunə

    Go, buy some bread!

    Bring me some juice!

  5. Some özündən sonra of hissəciyini qəbul edir. Bu halda xəbər some of-dan sonra gələn isimdən asılıdır.

    Some of + (the) cəm isim + cəm xəbər
    Some of + (the) sayılmayan tək isim + tək xəbər

    Nümunə

    Some of the girls are here.

    Some of the money is here.

  6. Some + one = Someone (kimsə), Some + body = Somebody (kimsə), Some + thing = Something (nə isə).

    Bu əvəzliklər mürəkkəb əvəzliklərdir, yalnız təsdiq cümlələrində işlənir. Xəbəri həmişə təkdə tələb edir. Özündən sonra heç vaxt isim tələb etmir və of hissəciyini qəbul etmir.

Any

  1. Any — some-ın sinonimidir. Sual və inkar cümlələrində some-ın yerinə işlənir. Özündən sonra of hissəciyini qəbul edir və any of-dan sonra xəbər isimlə uzlaşır.

    Any of + (the) cəm isim + cəm xəbər
    Any of + (the) sayılmayan tək isim + tək xəbər

  2. Any təsdiq cümlələrində işlənərsə, tərcüməsi istənilən olur.
    Nümunə

    You can call me at any time.

  3. Any if-dən sonra şərt budaq cümləsində işlənə bilər: If + any
    Nümunə

    If you need any help, I’m here.

  4. Without sözönündən sonra any işlənir.
    Nümunə

    I can do it without any help.

  5. Qısa inkar cavablarında yalnız any işlənir.
    Nümunə

    – Do you have any friends?
    – No, I haven’t got any!

  6. Anybody, Anyone, Anything + of / isim = OLMAZ! Bunlar sual və inkar cümlələrində işlənir.

A lot of

A lot of — çoxlu deməkdir. Yalnız təsdiq cümlələrində işlənir və bütün növ isimlərlə işlənir.

A lot of + cəm isim + cəm xəbər
A lot of + sayılmayan tək isim + tək xəbər

Nümunə

There are a lot of children in the yard.

There is a lot of snow in the yard.

Bu cümlələri sual və inkara çevirsək, much və ya many işlənəcək:

Quruluşİşlənmə
Much + sayılmayan tək isimIs there much snow in the yard?
Many + sayılan cəm isimAre there many children in the yard?
How much + sayılmayan tək isimHow much water is there?
How many + sayılan cəm isimHow many books are there?
!
Diqqət: Sayılmayan isimlə sual qurarkən Is there işlənir: “Are there much snow?” ✘ / “Is there much snow?” ✔.

Little / Few

Little + tək sayılmayan isim
Few + cəm sayılan isim

9Relative Pronouns Nisbi əvəzliklər

To relate — birləşdirmək deməkdir. Nisbi əvəzliklər təyini budaq cümləsini baş cümləyə bağlayır. Budaq cümlə baş cümləni yarıya bölür.

Nümunə

The girl who is playing there is my friend.

Qaydalar

  1. Əgər baş cümlənin mübtədası canlıdırsa, budaq cümlə baş cümləyə who, whose, whom bağlayıcıları ilə bağlanır.

    Who + xəbər
    Whom + isim
    Whose + isim

    Nümunə

    The girls who are late for the lesson are my friends.

    The girl whose name is Sona is here.

    The girl whom you see here is my classmate.

  2. Əgər baş cümlənin mübtədası və ya tamamlığı thing, everything, nothing, something, anything ilə işlənərsə, that nisbi əvəzliyi işlənəcək.
    Nümunə

    The only thing that he wanted to know is the truth.

  3. Əgər cümlənin mübtədası cansız isimlə ifadə olunarsa, budaq cümlə baş cümləyə which, that bağlayıcısı ilə bağlanacaq.

    Cansız isim + which + xəbər
    Cansız isim + that + isim

    Nümunə

    The book which is on the table is mine.

  4. Baş cümlənin mübtədası yer ilə ifadə olunarsa (the place, the city, the factory, the house, the village və s.), budaq cümlə baş cümləyə where ilə bağlanacaq.
    Nümunə

    The factory where my dad works makes cars.

10Defining Pronouns Təyini əvəzliklər

1. All

  • All — bütün, hamı, hər şey deməkdir. Özündən sonra sayıla bilən cəm və sayılmayan tək isim tələb edir.
  • All canlıya aiddirsə hamı, cansıza aiddirsə hər şey kimi tərcümə edilir.
  • All yalnız cəm əvəzliklərlə işlənir: You all = all of you; They all = all of them.
  • All of hissəciyini də qəbul edir.

2. Both

  • Both — hər iki və ya hər ikisi deməkdir. Özündən sonra həmişə yalnız cəm isim və cəm xəbər tələb edir.
  • Both da yalnız cəm əvəzliklərlə işlənir.
  • Both da of hissəciyini qəbul edir.
  • Both … and qoşa bağlayıcısı yalnız təsdiq cümlələrində işlənir və xəbəri həmişə cəmdə tələb edir.

3. Every / Each

  • Every / Each — hər, hər biri kimi tərcümə olunur. Özündən sonra yalnız sayıla bilən tək isim tələb edir.
  • Nümunə: Every girl, Each book.
  • Every-nin sonuna body, thing, one əlavə edərək mürəkkəb əvəzlik əmələ gətirmək olar: Everybody, Everything, Everyone.
  • Bu mürəkkəb əvəzliklər özündən sonra heç vaxt of, isim qəbul etməz və xəbəri həmişə təkdə olar.

4. One

  • One təyini əvəzlik kimi mütləq cümlənin mübtədası olur.
  • Xəbəri mütləq can, may, must, should, could kimi modal feillərlə ifadə olunmalıdır.
Nümunə

One must obey the rules.

5. Other / Another

  • Other — başqası, digəri kimi tərcümə olunur. Özündə ismin bütün funksiyalarını daşıyır, özündən sonra bütün növ isimləri qəbul edir və xəbər isimlə uzlaşır.
  • The other — tanıdığım, bildiyim başqa biri deməkdir.
  • Another — hər hansı başqa biri deməkdir. Özündən sonra tək və sayıla bilən isim tələb edir.
Nümunə

I have 2 daughters. One of them is a doctor, the other is a teacher.

Bring me another pen.

11Negative Pronouns İnkar əvəzlikləri

Cümləni 4 yolla inkar etmək olar:

  1. Köməkçi feillərə not hissəciyi artırmaqla.
    Nümunə

    I don’t go home.

    She will not help me.

    He isn’t here.

  2. Cümləni never, hardly, no sooner, scarcely, nowhere, no more, no longer kimi inkar zərflərindən istifadə etməklə.
    Nümunə

    I have never been to the USA.

  3. Cümləni neither … nor qoşa bağlayıcısı ilə də inkar etmək olar. Əgər bu bağlayıcılardan sonra tək və sayıla bilən isim gələrsə, a/an artikli işlənəcək.
  4. Nobody, Nothing, No one + isim, of = OLMAZ! Xəbər hər zaman təkdə olur.

No

  • No — heç deməkdir, özündən sonra bütün növ isimləri qəbul edir (tək, cəm, sayılan və sayılmayan).
  • No + a / an / the / another / the other = qəbul etməz
  • No + other = işlənə bilər
